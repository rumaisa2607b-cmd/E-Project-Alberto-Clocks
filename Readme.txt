# ALBERTO WATCH COMPANY
### Luxury Watches | 3D Experience | Premium Timepieces

---

## 1. Project Introduction

Alberto Watch Company is a modern, responsive luxury watch website developed to provide customers with an elegant online shopping and browsing experience.

The website features luxury watch collections, interactive product details, 3D watch animations, technology information, a gallery, store locator and customer support.

## 2. Project Objectives

- Create an attractive luxury watch website.
- Display different watch collections.
- Provide an interactive 3D watch experience.
- Show product information and prices.
- Make the website responsive on mobile, tablet and desktop.
- Provide company information and customer contact details.

## 3. Main Features

1. Responsive navigation bar.
2. Luxury homepage and hero section.
3. Vintage, Luxury, Classic and Smart watch collections.
4. Product cards with images and prices.
5. Product details popup.
6. Interactive 3D rotating watch.
7. Exploded watch animation.
8. Watch assembly animation.
9. Technology and innovation section.
10. Product image gallery.
11. Store locator section.
12. About Us and Contact Us sections.
13. Visitor counter.
14. Live date and time.
15. Geolocation feature.
16. Smooth scrolling and CSS animations.

## 6. Installation Instructions

1. Install Visual Studio Code.
2. Open the Alberto Watch Company project folder.
3. Make sure all project files are inside the same folder.
4. Install the Live Server extension in VS Code.
5. Right-click on index.html.
6. Select Open with Live Server.
7. The website will open in your default browser.

An internet connection is required for external libraries, fonts and online images.
